# Paper Reading · 个人版 0.2

个人论文精读工作台。纯前端，无需构建；数据保存在当前浏览器（localStorage + IndexedDB）。

## 运行

```bash
cd paper-reading-v2
./start.sh            # 启动 serve.py（禁用缓存的静态服务）并自动打开浏览器；也可以 python3 -m http.server 8080
```

打开 http://localhost:8080 。不要用 file:// 打开（ES 模块和 IndexedDB 需要 http）。用普通的 http.server 时，改过代码后需要强制刷新（Ctrl+Shift+R）才能绕过浏览器缓存。

单元测试（纯逻辑：迁移、锚点、复习排期、导出、统计）：

```bash
node --test tests/
```

## 这一版做了什么

- **信息架构**：首页是行动页（继续阅读、今日复习、待解决问题、收件箱），论文库、知识、设置各一页；阅读器从论文进入。
- **数据模型 v2**：Paper / Session / Event / Note(Anchor) / KnowledgeItem / Review 六类对象，带 schemaVersion 和从旧版 `paper-reading-v1` 的自动迁移（旧数据保留不动）。
- **PDF 阅读器**：PDF.js 4.10（已 vendored）渲染页面和文字层，可直接划词；高亮按页面归一化坐标保存，缩放后仍然对位。
- **文本视图**：只给没有 PDF 的论文用（粘贴原文），按字符偏移保存锚点，同一个词多次出现、重叠高亮、文本修改后重定位都正确。有 PDF 的论文始终显示 PDF，不再有 PDF / 文本切换。
- **阅读交互**：选区浮动工具栏是唯一即时入口（翻译 / 解释 / 提问 / 高亮 / 笔记 / 存表达）；翻译在选区旁浮层显示，解释和追问进右侧助手；反馈按钮放在回答顶部；图解默认折叠。没有选区时提问或点「总结全文」，会把整篇 PDF 的文字（按页标注）一起发给模型。
- **阅读会话**：打开论文自动开始会话，「结束本次阅读」三选一（读完了 / 读了一部分 / 先放着），不再一键 Completed。
- **复盘页**：左边是真实证据（会话、仍不理解、高亮、笔记、提问），右边是三个问题的自由文本（自动保存）+ 结构化的概念条目和学术英语条目。AI 草稿只依据证据生成，与人工内容分开保存。
- **图解**：Mermaid 流程图带配色和分组（输入蓝、计算黄、输出绿、损失红，模块用子图，边上标注流动的量），模型也可以直接画经 DOMPurify 过滤的 SVG 示意图（分子、坐标、几何关系这类自由插图），点击可放大。
- **原文处的笔记**：写了文字的笔记和疑问会在它所属的那段文字末尾留一个 ✎ 小标记（高亮和翻译不留）。点标记或点高亮本身，笔记卡片就在旁边弹出（看、编辑、删除、跳到侧栏）。
- **给模型看图**：阅读器里点「截图提问」（快捷键 I）在 PDF 上拖一个框，框住图、表或公式，框选后截图会附在右侧助手的提问框里：直接点「解释这张图」「翻译图中文字」，或输入问题后发送，截图连同本页文字发给当前模型；通用于所有支持图片输入的模型（DeepSeek V4、Claude、GPT 等），不依赖任何一家的 PDF 文件接口。回答卡片带缩略图，点击回到原图位置。设置里可开启「全文提问时附带每页截图」。
- **回答的排版**：Markdown 完整渲染（小标题、段落、嵌套列表、引用、表格、链接），LaTeX 公式用 KaTeX 渲染（行内 $…$、独立 $$…$$、\( \) 都支持），Mermaid 画流程图、结构图、时序图；三个库都已 vendored，首次用到时才加载。输出被截断时有「继续生成」。
- **解释风格**：设置里可选「面向非本领域读者」或「面向同领域研究者」，提示词按 ChatGPT / Claude 式的讲解结构写：先结论再展开、段落为主、术语首次出现给英文和解释、公式解释符号。每个平台可以另设一个翻译用的快速模型。
- **查词与生词本**：选中单词先查内置离线词典（ECDICT 子集，5.8 万词条加 3.3 万变形，零延迟，显示音标、释义、考试标签），一键「加入生词本」；生词本是全局的，每个词记录它出现过的句子、论文和页码，按 1/3/7/14/30 天排入复习。选区是短语时走 AI，提示词改为「本句中的意思 + 常见释义」，不会再说无法翻译。「最近查过」列表记录查过但没收录的词，查过两次以上会提醒。设置里可打开「查词自动进生词本」（默认关）。跨行连字（chemi- cal）会自动合并。
- **翻译速度**：DeepSeek V4 模型默认带推理，翻一句话要 5 到 7 秒；现在翻译和低思考深度的调用关闭推理，一句话约 1 秒。模型推理时侧栏显示「模型思考中」。
- **全文翻译**：顶栏「全文翻译」在每页 PDF 右边加一列译文，逐页对照：每段译文放在原文段落的高度，鼠标悬停会在 PDF 上标出对应的原文；图、表、公式都还在原来的页面里。段落由 PDF 文字行的缩进、行距和字号重排得到，用当前平台的快速模型逐段翻译（不开推理），按段落内容缓存在本机 IndexedDB，翻译过一次后再打开直接显示，不会重复调用。按钮切换显示 / 隐藏，⋯ 菜单里有继续翻译、重新翻译、删除译文。
- **知识**：三类条目。概念＝定义 + 我的理解，并关联它来自的那条解释，随时「查看解释」；生词＝音标、释义、出现过的句子和页码；表达＝含义用法 + 我的例句。入口：解释 / 提问回答下方「存为概念」会自动填入术语和一句话定义；导读回答的术语表可一键「导入术语表」；查词「加入生词本」；选区「存表达」。1、3、7、14、30 天间隔复习，首页今日复习按类型给出不同的提问；阅读器右侧「知识」页签按类型分组，可跳回解释或原文。
- **AI（个人模式，多平台）**：设置页为 Anthropic、DeepSeek、OpenAI 兼容网关分别保存 Key、模型和 API 地址，随时切换「当前使用的平台」。浏览器直接调用各平台接口，Key 只存本机，备份文件里不含 Key。流式输出，可停止；每条回答记录平台、模型和耗时。Anthropic 走官方 SDK 并支持思考深度（翻译固定低深度），已开启服务端拒绝回退；DeepSeek 与 OpenAI 兼容走 chat completions 流式接口。按论文可勾选「不发送给 AI」。
- **数据**：JSON 备份导出 / 恢复（合并，不覆盖），知识 Markdown 导出，复盘 Markdown 导出，「复制并打开 Notion」手动归档。
- **可靠性**：保存失败会显示错误并提示导出备份，不再误报成功；导入失败回滚；损坏数据另存副本后以空库启动。


## 部署

`./build.sh` 生成可直接上传到任何静态托管的 `dist/`。三种上云层次、各平台步骤和注意事项见 `DEPLOY.md`。

## 没有 Key 时怎么测 AI 链路

仓库带一个本地的 Anthropic 接口模拟服务，用来联调界面，不花钱也不需要网络：

```bash
python3 tests/mock-anthropic.py 8090
```

然后在设置页：启用 AI，在任一平台栏位里 Key 随便填（填 `bad` 会模拟 401），API 地址填成 `http://localhost:8090`，保存后点「测试连接」。模拟服务同时提供 Anthropic 格式和 OpenAI 兼容格式。
提问里带 `SLOW` 会慢速输出（用来测「停止」），带 `REFUSE` 会模拟模型拒绝。用完把 API 地址清空即可回到官方接口。

## 没有做 / 没验证

- 没有登录、云同步、Notion 自动写入、OCR、多模型路由。
- AI 链路用上面的模拟服务跑过完整流程：SDK 浏览器加载、流式输出、停止、401 错误、拒绝、重试、翻译浮层、复盘草稿。DeepSeek 用真实 Key 在浏览器里验证过翻译和解释；Anthropic 与 OpenAI 官方接口没有用真实 Key 验证过，配置后请先点「测试连接」。
- 浏览器验证用 Chromium 1440×900 完成：首页、论文库、文本阅读、PDF 导入与划词高亮、翻译浮层、结束会话、复盘自动保存、知识条目、设置、v1 迁移、全文翻译（模拟服务）、截图附到提问框、术语表导入。未验证：触屏、Safari / Firefox、超大 PDF、扫描件。
- 教学示例可以在设置页删除或恢复。
